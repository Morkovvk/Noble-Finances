# Noble Finances

Responsive landing page for a financial services company, built from a Figma design.

**Live demo:** https://morkovvk.github.io/Noble-Finances/

![Noble Finances](screenshot.png)

## Tech stack

HTML, CSS, vanilla JavaScript. No frameworks, no build step.

## Features

- Responsive layout: desktop, tablet, mobile
- Accessible tabs with keyboard navigation
- Semantic HTML
- Optimized images: WebP, `srcset`, lazy loading

## Running locally

`npx serve`
