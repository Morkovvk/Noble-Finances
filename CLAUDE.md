# Noble Finances

Статичний лендінг, зверстаний з Figma-дизайну. Перший навчальний проєкт.

## Стек

Чистий HTML + CSS + vanilla JS, без збірки і без залежностей.

- `index.html` — уся розмітка сторінки
- `style.css` — усі стилі; CSS custom properties, native nesting, media queries
- `script.js` — перемикання табів у секції testimonials
- `images/` — картинки (наразі PNG)
- Шрифти: Work Sans і DM Sans з Google Fonts

## Як запустити локально

Збірки немає — потрібен будь-який статичний сервер з кореня репозиторію:

    npx serve

або Live Server у VS Code.
